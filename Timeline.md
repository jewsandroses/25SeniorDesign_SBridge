# Project Timeline

## Milestones

### Completing the Selection of Programming Languages and Main Design Documentation

This milestone will involve the section of the programming languages for each project subsystem and as well as more detailed technical design documentation on those subsystems. This documentation will include a list of API endpoints, the necessary client side pages, the database schema, and other technical details.

### Completion of the Media Transformer

This will involve the completion of the Media Transformer which gets media prepared for being saved to the database. The deliverable for this milestone will involve the completion of this subsystem and the ability to feed in a piece of media to this subsystem and get a result that would be ready to be saved to the database.

### Completion of the Database

This will involve the implementation of the design database scheme and the ability to save and retrieve pieces of media to and from the database. The deliverable for this will be the ability to build the database from scratch, save to the database, edit its entries, and retrieve media.

### Completion of the Logic Module

This will be the completion of the Logic Module. This will include the ability to search through the contents of the database, add tags to elements within the database, create connections between elements within the database, and create citations for media elements within the database.

### Completion of the API

This will be the completion of the API. This will involve the ability to make calls to the API to execute the functionality of the previously implemented subsystems.

### Completion of the Client

This will be the completion of the client. This will involve the ability to make calls to the API to execute the functionality of the project, save media elements to the project, and retrieve media elements to the project.

### Final Project Delivery

This will be the final complete project. This will include any refinement of the subsystems, resolving any outstanding bugs, and final tests of the complete system.
