# User Stories
- [ ] As a user, I want to be able to save an article, so that I can access the article at a later date
- [ ] As a user, I want to be able to search through my archive, so I can locate an article that I have previously saved
- [ ] As a user, I want to be able to get a plain text version of an uploaded PDF, so that I can more easily read it
- [ ] As a user, I want to be able to create a citation for an article based on the text of an article, so that I can cite it
- [ ] As a user, I want to be able to get a summary of an article, so that I can better understand an article at a glance
- [ ] As a user, I want to be able to tag an article, so that I can more easily find it later
- [ ] As a user, I want to be able to see what other articles an article cites, so that I can better see the connections between articles
