# Individual Capstone Assessment
Sean Bridge

The intention of this project is to create a self-hosted and run application that grants a user the ability to add, categorize, read, and generally manage a variety of types of literature and media. Academically this project is going to cover a range of different fields of computer science. The project will need to have a database with multiple tables in it to categorize the various pieces of media. There will be elements of text parsing, compression, storage, and potentially natural language parsing. In order for the program to not just be a command line application, a graphical user interface will need to be created in order for a user to interface with the design. Additionally, the intention is for the application to be able to be hosted on one device and accessed remotely, which will require a certain level of network management and if there is sufficient amount of time I would like to add the capability for this remote access to be integrated directly into someone’s browser via a browser extension. These different aspects will then come together to allow a user to seamlessly add academic or news articles to their own personal local repository for them to freely access, search for, or reference any time they would like.

I have touched upon most if not all of these academic areas in the classes that I have taken. The database and data management set-up will rely upon my experience in my “Database Design and Development” (CS4092) course. In that course I learned the optimal ways to design and layout  a database, as well as the necessary SQL skills to create and manage a database. Any networking components will rely upon knowledge I learned in my “Computer Networks” (CS4065) course. This will include things such as the best way to send networking messages between a host and client, methods of redundancy to prevent message loss on networks with connection issues, and if necessary creating a custom messaging protocol to transfer the needed information from a client to a host. My “Software Engineering” (EECE3093C) course taught me the basics of actually laying out and executing a software project. I’ll be able to use this experience to better layout and then track the different tasks that I need to complete as part of this project.

During my co-op rotations, I also worked directly on many of the same areas of expertise that this project will work on. During my time as a Technical Intern at Northrop Grumman, I worked in a team that used an Agile-Sprint framework for their project and assisted in designing some of the stories for that project which will help me do the same for this project. Additionally, while working on that team I worked quite a bit on interfacing with and designing API endpoints to communicate commands and data between different pieces of software, which will be essential for adding and retrieving different pieces of media from the application described in this project. While working as a Quality Assurance team member at London Computer Systems designed and executed tests on many different types of applications. This experience will help me do the same for this project and ensure that the software actually functions as I intend it to. Additionally, once I transferred to being a Software Developer there, I worked primarily on creating database revisions and API endpoints for their VOIP phone system NetDialTone (NDT). This will help me develop a robust system for managing the database and API revisions within this project. 

I am highly motivated to work on this project because I think this piece of software could fulfill a unique niche that is not already filled by other available softwares within the field. Most existing software of this type are cloud-based systems, which removes the control and ownership that a user has over their own information. Increasingly software is becoming more and more cloud based and removed from the direct control and ownership of its user and subject to the profit driven whims of their corporate developers. I find a lot of value in software that is readily available for its users to use on their own, in perpetuity. Additionally, I think if this is executed well, this is a type of software that I would use myself when researching for projects, reading the news, or writing articles. Overall, I am excited about this project because I find it to be something novel and that I would happily use in my everyday life.

I plan to approach this project in an iterative manner, ensuring that each part of the project that I make is functional on its own first. This will make it significantly easier to integrate the parts together once they are complete, as well as troubleshoot any problems that may arise during this integration. This process will most likely start by creating a series of command line tools -- which can also be imported as libraries -- which fulfill the rudimentary functions of the software. The next step will be integrating these tools together into a single command line tool that fulfills the main functions of the software in text form. Then I’ll add the graphical layer on top of this text based tool and beyond that work on the more advanced bells and whistles that would turn this project from a novelty program into a truly robust tool (ie. remote web interface, browser based extension, etc). The success of this project is going to be determined by if a user can carry out the basic functions of adding, categorizing, and retrieving articles within the program in a simple and straightforward manner.
