# Task List
List of tasks for the completion of Taynakh. 

Each task is categorized as part of a feature within a subsystem of the project.

## General
- [ ] Research what programming languages, existing libraries, or tools would be best for each project subsystem
- [ ] Develop a comprehensive testing process for each subsystem based on the subsystem's chosen programming language
- [ ] Develop the process for deploying the project (both for development and production)

## Media Transformer
- [ ] Develop the process for taking a plain text article and preparing it for being saved in the database
- [ ] Develop the process of scraping the text of an article for metadata (ie author, publication date, other citations, etc)
- [ ] Develop the process for taking a PDF and turning it into plain text to be processed
- [ ] Develop the process of taking an audio/visual media format and transcribing it into plain text
  

## Logic Module
- [ ] Develop the database search functionality
- [ ] Develop the process for generating citations based on an article's metadata

## Database
- [ ] Specify the database schema (tables, connections between tables, revision tracking, etc)
- [ ] Implement the database schema
- [ ] Implement the media storage (both saving and retrieving of media)

## API
- [ ] Specify and Document the API endpoints that the program will have
- [ ] Implement the necessary API endpoints

## Client
- [ ] Design and document the necessary page layout a client program would have
- [ ] Create a webpage based client to interface with the server
- [ ] Create a browser extension to interface with the server
