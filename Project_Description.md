## Project Description

Taynakh is a play on the term “Tanakh”, which is the term used for the collaborative summarization of Jewish law. This project is intended to create an open-source and  self-hosted repository of media for the use in personal and academic settings. A user will be able to curate their own collection of academic sources for them to sort, create links between, generate citations for, and search for quotes within.

## Problem Statement

 When reading and writing academic articles it can be difficult to store and arrange said media in a simple, comprehensive, and elegant manner outside of a collection of paid subscription services. This project seeks to solve the problem of storing, organizing, and generating citations for different forms of media (primarily written media).

## Inadequacy of Current Solutions

Most solutions that currently exist are paid subscription services which host a user's articles within the cloud and blocks many of the more advanced features behind paywalls. This project seeks to return the power directly back to users by allowing them to self-host and manage their own repository of articles on their own hardware.

## Approach, Goals, & Expectations

Development of this project will take an iterative approach. Starting with designing the base tools of the project as comandline tools first. Then compiling these component tools together into a single comprehensive tool which will eventually be interacted with via a web based user interface.
